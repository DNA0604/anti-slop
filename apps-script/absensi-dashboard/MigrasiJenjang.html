Persiapan pada salinan database

Struktur Jenjang Pelatihan

Satu Jenjang awal untuk setiap program lama. Jenjang berikutnya ditambahkan melalui Pengelolaan.

Gunakan salinan spreadsheet dan proyek Apps Script. Proses menambahkan sheet Jenjang serta kolom id_jenjang pada Sesi dan Keikutsertaan. ID lama, rumus, nilai dan histori tetap dipertahankan.

Memuat pemeriksaan sumber…

Pemetaan yang Akan Digunakan

ProgramSesi / KeikutsertaanNama Jenjang Tujuan

Umum digunakan untuk program tanpa tingkatan. Periksa nama dan pastikan satu program lama tidak mencampur beberapa kelompok.

Migrasi Tersimpan

Kelanjutan memakai rencana dan cadangan sebelumnya. Data baru atau perubahan di luar rencana akan menghentikan proses.

Cadangan rencana disimpan pada Riwayat_Validasi. Bila proses terputus, penulisan aplikasi ditahan sampai migrasi selesai atau persiapan yang belum mengubah struktur dibatalkan.

Lanjutkan persiapan struktur Jenjang?

Pastikan sumber adalah salinan database. Proses akan memakai pemetaan yang telah diperiksa dan mempertahankan data lama.
