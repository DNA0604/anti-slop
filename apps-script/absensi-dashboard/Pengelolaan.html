Periksa Data

Pilih cakupan pemeriksaan pada tujuh sheet inti. Tidak mengubah data. NIP dummy 12 digit ditandai sebagai informasi.

Belum diperiksa.

TINGKAT SHEET BARIS ID TEMUAN SARAN

Pemeriksaan mencakup header wajib, ID unik, data wajib, NIP, relasi, kesesuaian program, duplikasi keikutsertaan/kehadiran, dan kelengkapan waktu kehadiran. Belum mencakup seluruh aturan JP, jadwal jeda, log QR, atau audit transaksi. Untuk program terpilih, hanya record terkait yang diperiksa; masalah struktur sheet tetap ditampilkan karena dapat membatasi hasil. Data tanpa hubungan program dapat diperiksa melalui Seluruh database. Hasil mengikuti data saat pemeriksaan; maksimal 1.000 temuan ditampilkan.
