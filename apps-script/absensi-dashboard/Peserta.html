Gunakan akun pemilik spreadsheet. Jika identitas akun tidak tersedia melalui Web App, buka menu Manajemen Pelatihan → Buka Peserta Program di spreadsheet.

Pilihan ini menentukan program tujuan pendaftaran dan daftar peserta.

01 · SIAPKAN DATA

Impor Peserta Program

Peserta cukup didaftarkan sekali untuk seluruh sesi dalam program yang dipilih.

Kolom wajib: nip, nama_pegawai, unit_kerja. NIP harus berupa teks 18 digit. Template Excel sudah menyiapkan format teks pada kolom NIP. Jika memakai CSV di Excel, impor kolom NIP sebagai teks; digit yang sudah dibulatkan tidak dapat dipulihkan hanya dengan mengubah format.

File akan dibaca setelah dipilih. Data belum disimpan.
