PESERTA JP DIPEROLEH JP ACUAN KEKURANGAN JP PEMENUHAN STATUS JP NILAI PERILAKU STATUS PERILAKU NILAI KESELURUHAN
Pilih program untuk memuat rekap.

Acuan = total durasi efektif sesi ÷ 45. JP diperoleh hanya menjumlahkan hasil perhitungan yang sesuai data terbaru. Kekurangan dan persentase pada rekap sementara masih dapat berubah. Status lengkap menunjukkan kelengkapan data, bukan keputusan kelulusan. Nilai perilaku mengikuti aturan aktif program; tanpa catatan, nilai awal masih digunakan. Nilai keseluruhan belum dihitung karena komponen dan bobot penilaian belum lengkap. Unduhan mencakup seluruh peserta, termasuk yang tersembunyi oleh pencarian. Muat ulang sebelum mengunduh hasil terbaru.

PESERTA TAMBAHAN DIAKUI PENGURANGAN NILAI KONTRIBUSI BERBOBOT STATUS

Aturan program belum dimuat.

Nilai = nilai awal + tambahan positif yang dibatasi − pengurangan, dibatasi 0–100. Klik nama peserta untuk rincian. Hasil dihitung langsung dari data saat dimuat; belum ditulis sebagai poin disahkan atau nilai akhir pelatihan. Nilai awal tetap berlaku jika belum ada catatan; ini belum berarti peserta telah dinilai secara menyeluruh.
